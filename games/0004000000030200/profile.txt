# ---- aiming without the stylus. The player's aim object (reached from 0xe14504; land battles: vtable 0xcf1c34, air
# battles: 0xcf1be0) holds the reticle (top-screen pixels at +0xa4, +0xa8). Each frame 0x6d27e8 sums the stylus's
# motion and the aim stick's into a delta (sp+8, sp+0xc; per second: it is multiplied by the frame time, in s16), then
# turns the camera with it (land) and moves the reticle. The virtual call it makes in between (vtable +0x30: 0xa9ac40
# on land, 0xaf7918 in the air) returns to 0x6d2820: the mouse's motion is added there. The pad state the game copies
# for the player (0xa3f050, r1) holds the control mode at +0 (2: aiming with a stick, the floats at +0x48, +0x4c).
value aim_vt = u32 0xe14504 > 8 > -0x10
aim pad 0xa3f050 mode 0 2 stick 0x48 0x4c
aim delta 0x6d2820 8 12 per s16 on 0xa9ac40 0xaf7918
aim when aim_vt == 0xcf1c34 or aim_vt == 0xcf1be0
