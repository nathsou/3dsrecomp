# Kid Icarus: Uprising (EUR). Format: runtime/profile.cpp.

# ---- aiming without the stylus. The player's aim object (reached from 0xe14504; land battles: vtable 0xcf1c34, air
# battles: 0xcf1be0) holds the reticle (top-screen pixels at +0xa4, +0xa8). Each frame 0x6d27e8 (r4: the object)
# sums the stylus's motion and the button aiming's into a delta (sp+8, sp+0xc; per second: it is multiplied by the
# frame time, in s16), then turns the camera with it (land) and moves the reticle. The virtual call it makes in
# between (vtable +0x30: 0xa9ac40 on land, 0xaf7918 in the air) returns to 0x6d2820: the stick and the mouse are added
# there. The byte at +0x1bc is set while the game's button aiming has input; without it the reticle goes back to the
# middle each frame (0x76ed88), as when the stylus is lifted, and the camera never turns.
value aim_vt = u32 0xe14504 > 8 > -0x10
aim delta 0x6d2820 8 12 per s16 active r4 0x1bc on 0xa9ac40 0xaf7918
aim stick 320

# ---- one screen: battles play on the top screen (the bottom one, with the dialogue, comes up in the corner when it
# changes); elsewhere (the pause menu too) the menus, which are on the bottom screen, come up as a panel over the top
# one (they all take the d-pad and A/B).
value playing = u8 0xe17514                     # 0 while a battle is paused (its menu is on the bottom screen)
focus top when aim_vt == 0xcf1c34 and playing == 1 or aim_vt == 0xcf1be0 and playing == 1
aim when aim_vt == 0xcf1c34 and playing == 1 or aim_vt == 0xcf1be0 and playing == 1
focus panel
