# Resetti: each player's "session under way" bit (set when play starts, cleared by both saves), in the first part of

# ---- one screen (the "Top screen only" layout): the bottom screen never shows as such. Its menus come up as a
# panel over the top screen, its background (the plaid wallpaper) hidden so dialogs float; the field's map and
# tabs are reached through the hub (ZL), the map (-) and the other overlays.
onescreen
value single = runtime single
value debug = runtime debug
value map = u32 0x94fc3c                       # the BsMenuMap page (the field's map): set while it shows
# BsMenuBg's layout: N_mvmnt_Uscrn > P_base_00 (the plaid), hidden (alpha 0: not drawn). The bottom screen's pass
# reuses the top screen's render target, so it is cleared to transparent first ("clearbottom").
clearbottom
value bg_alpha = u8 0x94f708 > 0x78 > 0xbc > 0x14 > 0xb0
set bg_alpha = 0 when single == 1
set bg_alpha = 255 when single == 0 and debug == 0
set bg_alpha = 0 when debug == 1
focus top when map != 0
focus panel
value pockets_open = u32 0x94f9dc               # the BsMenuItem page (the pockets): set while it shows
value pocket0 = u32 0xaaf14c > 0x6bd0           # the current player's first pocket (16 items, 4 bytes apart)
value held = u16 0xaaf14c > 0x26                # the item in the player's hands

# Controls in the manner of a single-screen Animal Crossing: X the pockets (the game's own), ZL a hub of the bottom
# screen's buttons, - the map, the d-pad the tools in the pockets (up: the ring; left/right: the previous/next one;
# down: put it away), the right stick the camera (up: look up, as L and R do) and a pointer over menus (ZR
# touches where it points).
bind zl hub
bind back map
bind dup tools
bind dleft tool-prev
bind dright tool-next
bind ddown tool-away
bind zr pointer
bind rs-up R

# the hub: the field's buttons (bottom-screen pixels), their icons kept from the bottom screen
hub "Pockets" press X icon 2 0 46 22 when map != 0
